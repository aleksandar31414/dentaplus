# 🦷 DentaPlus – стоматолошка ординација со онлајн закажување

Динамичка веб-апликација (MERN: **MongoDB, Express, React, Node.js**) за стоматолошка ординација:
ценовник на услуги, профили на стоматолози, **онлајн закажување термини** (слободните часови се пресметуваат
според работното време, другите закажувања и државните празници), **забен картон** по заби (FDI шема),
рецензии од пациенти и статистика за ординацијата. Државните празници се читаат од надворешниот **Nager.Date API**.

**Изработил:** Aleksandar Dimitrovski · **Професор:** Наташа Табаковска

> 🌐 Продукциска верзија: `https://dentaplus.onrender.com` *(заменете со вашиот линк по објавување)*
> 📘 REST API документација: `/api/docs/` · OpenAPI спецификација: `/api/swagger.json`

**Правила за закажување (деловна логика):** термин најмалку 1 час однапред и најмногу 90 дена;
само во работните денови и часови на стоматологот; не во недела и државни празници; чекор од 30 минути;
без преклопување со друг термин; најмногу 3 отворени термини по пациент; пациентот може да откаже најдоцна 24 часа пред терминот.
Статуси: `pending` (чека потврда) → `confirmed` → `completed` (се внесуваат записи во картонот) или `cancelled`.

## 🗄️ Колекции (MongoDB)

| Колекција | Опис | Зависи од |
|---|---|---|
| **users** | пациенти и админ, улога `user`/`admin`, телефон, bcrypt лозинка | – |
| **dentists** | стоматолози: специјалност, искуство, работни денови и часови | – |
| **services** | услуги: категорија, цена (ден.), траење | – |
| **appointments** | термини: пациент, стоматолог, услуга, почеток/крај, статус, цена | **users**, **dentists**, **services** |
| **reviews** | рецензија (1–5 ★) по завршен термин, одговор од ординацијата | **appointments**, users, dentists |
| **records** | забен картон: заб (FDI), интервенција, белешка | **users**, appointments, dentists |
| **activities** | историја на сите активности | users |

Каскадно бришење: корисник → неговите термини, рецензии и картон; термин → неговата рецензија.
Стоматолог со претстојни термини и услуга што е закажувана не може да се избришат (409) – може да се деактивираат.

## 🐳 Локално стартување со Docker (препорачано)

Предуслов: инсталиран [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```bash
cd dentaplus
docker compose up --build
```

| Адреса | Опис |
|---|---|

| http://localhost:3000/db | бришење / внесување иницијални податоци |
| http://localhost:3000/api/docs/ | Swagger UI документација |

## 💻 Локално стартување без Docker

Потребно: Node.js 20+ и локален MongoDB на `27017`.

```bash
cp .env.example .env
npm run install:all
npm run seed              # иницијални податоци
npm run dev:server        # API на http://localhost:3000
npm run dev:client        # React (Vite) на http://localhost:5173 (proxy кон /api)
```

## ☁️ Објавување во облак

**База – MongoDB Atlas**: бесплатен M0 кластер → *Database Access* → *Network Access* `0.0.0.0/0` →
connection string `mongodb+srv://<user>:<pass>@<cluster>.mongodb.net/dentaplus`.

**Апликација – Render.com** (Docker): проектот на GitHub → Render → *New → Blueprint* (`render.yaml`)
→ во *Environment* поставете `MONGODB_ATLAS_URI`. Кога `NODE_ENV=production`, се користи Atlas базата.
Временската зона е `Europe/Skopje` (работното време се смета по македонско време).

| Метод | Рута | Пристап | Опис |
|---|---|---|---|

| GET | /api/auth/me | корисник | тековен корисник |

| GET | /api/dentists/:id | сите | детали, распределба на оценки, број термини |
| GET | /api/dentists/:id/slots?date=&service= | сите | слободни термини за ден |
| POST · PUT · DELETE | /api/dentists(/:id) | админ | нов / измена / бришење |
| GET | /api/services(/:id) | сите | ценовник (q, category, minPrice, maxPrice, maxDuration, sort) |
| POST · PUT · DELETE | /api/services(/:id) | админ | |
| GET · POST | /api/appointments | корисник | свои термини (админ сите, филтри) / закажување (+ е-пошта) |
| GET · DELETE | /api/appointments/:id | сопственик, админ / админ | |
| PUT | /api/appointments/:id/cancel | сопственик (24 ч пред), админ | откажување |
| PUT | /api/appointments/:id/status | админ | потврди / заврши (+ записи во картон) / откажи |
| GET | /api/appointments/export.csv | админ | CSV извештај |
| GET · POST | /api/reviews | сите / пациент | рецензии (само за свој завршен термин) |
| PUT · DELETE | /api/reviews/:id | автор, админ | |
| PUT | /api/reviews/:id/reply | админ | одговор од ординацијата (+ е-пошта) |
| GET · POST · DELETE | /api/records | пациент (свој) / админ | забен картон |
| GET · PUT · DELETE | /api/users(/:id) | админ / сопственик | корисници и улоги |
| GET | /api/activities | корисник | историја (админ ги гледа сите) |

## ✅ Дозволени вредности за внесување

Интегритетот се проверува на три нивоа: **клиент** (`client/src/utils/validators.js`), **апликација**
(`server/middleware/validate.js`) и **шема** (Mongoose модели).

| Поле | Правило |
|---|---|
| Корисничко име | `^[a-zA-Z0-9._]{3,20}$`, уникатно |
| Е-пошта | `^[^\s@]+@[^\s@]+\.[a-zA-Z]{2,}$`, уникатна |
| Лозинка | најмалку 8 знаци, барем една буква и една бројка |
| Име / презиме | букви (вкл. кирилица), празно место, точка, цртичка |
| Телефон | `^\+?[0-9 /-]{8,18}$` |
| Специјалност | `general, orthodontics, surgery, endodontics, pediatric, prosthetics, periodontics` |
| Работни денови / часови | 1–6 (пон–саб), почеток 7–14 ч, крај 12–21 ч, најмалку 3 часа |
| Услуга | уникатно име, категорија од листа, цена 0–200.000 ден., траење 15/30/45/60/75/90/120 мин |
| Термин | правилата за закажување погоре; белешка до 300 знаци |
| Рецензија | оценка цел број 1–5, коментар 10–500 знаци, една по термин |
| Запис во картон | заб по FDI (11–18, 21–28, 31–38, 41–48) или празно, интервенција 2–80 знаци |
| URL на фотографија | `^https?://\S+$` |

## ✉️ Е-пошта

Без SMTP поставки пораките само се логираат во конзолата. За вистинско праќање поставете `SMTP_HOST`, `SMTP_PORT`,
`SMTP_USER`, `SMTP_PASS`. Се праќа: добредојде, потврда за закажан термин (до пациентот и до ординацијата),
промена на статус (потврден / откажан / завршен) и одговор на рецензија.
